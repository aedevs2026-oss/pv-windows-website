# PV WINDOWS Website

A responsive Next.js website concept for PV WINDOWS, based on publicly listed business information for the Mathikonpalayam, Dharmapuri business listing.

## Run locally

1. Install Node.js LTS from https://nodejs.org/
2. Open this folder in VS Code.
3. Open Terminal and run:
   ```bash
   npm install
   npm run dev
   ```
4. Visit http://localhost:3000

## Deploy

Push this folder to a GitHub repository and import that repository into Vercel. Vercel should detect Next.js automatically.
